# Flex Accordion Card v1.0.1

This minor release updates the installation guidance following approval for inclusion in the default integration catalog.

## Installation

In Home Assistant, search for **Flex Accordion Card** in the integration catalog and install it. If it is not visible yet, catalog synchronization may still be in progress.

For manual installations, replace the JavaScript file, use `/local/flex-accordion-card.js?v=1.0.1` as the JavaScript module resource, and reload the browser completely. Keep only one resource for this card.

The complete installation guide is available in the [README](../README.md), with translated guides for [French](README.fr.md), [Spanish](README.es.md) and [German](README.de.md).
