# Flex Accordion Card v1.0.2

This minor release updates the installation documentation in English, French, Spanish and German to use the built-in Home Assistant Marketplace.

## Installation

In Home Assistant, open **Settings → Marketplace**, search for **Flex Accordion Card**, and install it. The Marketplace manages dashboard resource registration for UI-managed resources. For YAML-managed dashboards, see the README for the resource path. A newly published version may take several hours to appear while the catalog synchronizes.

For manual installations, replace the JavaScript file, use `/local/flex-accordion-card.js?v=1.0.2` as the JavaScript module resource, and reload the browser completely. Keep only one resource for this card.

The complete installation guide is available in the [README](../README.md), with translated guides for [French](README.fr.md), [Spanish](README.es.md) and [German](README.de.md).
