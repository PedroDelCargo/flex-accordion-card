# Flex Accordion Card v1.0.3

This corrective release fixes the source files and distributable bundle following a build failure in v1.0.2. It contains no functional changes to the card.

## Installation

In Home Assistant, open **Settings → Marketplace**, search for **Flex Accordion Card**, and install it. For manual installations, replace the JavaScript file, use `/local/flex-accordion-card.js?v=1.0.3` as the JavaScript module resource, and reload the browser completely.

See the [README](../README.md) for full instructions in English, French, Spanish and German.
