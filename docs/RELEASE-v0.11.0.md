# Flex Accordion Card v0.11.0

Flex Accordion Card groups your Home Assistant cards into configurable accordion sections.

- Native Entity and Shortcut badges, with a live preview before adding them.
- Independent **Hide border** and **Transparent background** options for each badge.
- Contextual badge settings with type selection, content, interactions and visibility.
- Native Manual card creation, consistent editor controls and clearer section settings.
- English documentation by default, with complete French, Spanish and German guides.

## Installation

Download **flex-accordion-card.js** from the assets below and copy it to `<config>/www/flex-accordion-card.js`.

Add `/local/flex-accordion-card.js?v=0.11.0` as a **JavaScript module** dashboard resource, then reload your browser completely. When updating, replace the file and update the resource URL; do not add a duplicate resource.

[Features, configuration and examples](https://github.com/PedroDelCargo/flex-accordion-card#readme)

Shortcut badges require a Home Assistant frontend with native Shortcut badge support. HACS publication is deferred.
